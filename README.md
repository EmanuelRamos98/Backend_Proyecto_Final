# 📱 Proyecto Final: Simulación Básica de WhatsApp

Este es el proyecto final de la **Diplomatura en Desarrollo Web** de la UTN. Simula de forma básica parte del funcionamiento de WhatsApp. 🚀

---

## 🛠️ Tecnologías Utilizadas

Este proyecto está construido utilizando las siguientes librerías y herramientas:

- **Express**: Framework minimalista para aplicaciones web.
- **Bcrypt**: Para el hash de contraseñas y mayor seguridad.
- **Cors**: Gestión de políticas de origen cruzado.
- **Dotenv**: Configuración de variables de entorno.
- **Jsonwebtoken**: Implementación de autenticación basada en tokens.
- **Mongoose**: ODM para trabajar con MongoDB.
- **Nodemailer**: Envío de correos electrónicos.

---

## 🎯 Funcionalidades Principales

- Registro y autenticación de usuarios.
- Gestión de contactos.
- Envío de mensajes entre usuarios.
